CST 433 — Security in Computing

Semester: S7 (Elective II) Credits: 3-0-0 (3)

Course Modules & Topics

Module 1

Foundations of Security & Classical Ciphers

OSI security architecture, security attacks, services, and mechanisms. Cryptography vs Cryptanalysis. Classical encryption techniques, symmetric cipher model. Substitution ciphers: Monoalphabetic & Polyalphabetic, Caesar cipher, Affine cipher, Playfair cipher, Hill cipher, Vigenere cipher.

Module 2

Symmetric Key Cryptography (DES & AES)

Block vs Stream ciphers, Product ciphers, Feistel and Non-Feistel structures. Data Encryption Standard (DES): structure, key scheduling, weaknesses, Double DES, Triple DES. Advanced Encryption Standard (AES): transformation rounds, key expansion.

Module 3

Asymmetric Key Cryptosystems

Principles and requirements of public-key cryptography. The RSA cryptosystem: key generation, mathematical foundation, security attacks. ElGamal cryptosystem. Diffie-Hellman Key Exchange and Man-in-the-Middle (MitM) attack.

Module 4

Integrity, MAC & Digital Signatures

Cryptographic hash function requirements, SHA-512 architecture. Message Authentication Codes (MAC): HMAC, CMAC. Digital signatures: requirements, direct vs arbitrated signatures, attack models and forgery types.

Module 5

Key Distribution & System Security

Distribution of secret keys (symmetric & asymmetric), public key certificates. System security: Intruders, intrusion detection techniques, password protection. Malicious software: virus propagation, Trojan horses, DDoS (Direct & Reflector) countermeasures.
